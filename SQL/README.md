# SQL

This folder contains the complete SQL workflow for the Egypt household socioeconomic project.

## Files

1. `Cleaning.sql` — imports, cleans, standardizes, and integrates the survey data.
2. `Building Schema.sql` — builds the analytical database schema.
3. `Statistics.sql` — produces descriptive and validation statistics.
4. `Insights.sql` — contains the ordered analytical insights and recommendations.
5. `ERD Model.mwb` — MySQL Workbench entity-relationship model.

Run the scripts against the project database in the order documented in the root README.
